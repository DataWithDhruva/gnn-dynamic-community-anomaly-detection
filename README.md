# GNN-Based Approach for Dynamic Community Anomaly Detection in Fraud Networks

## 📌 Project Overview

This repository contains the documentation, project planning files, spreadsheets, prototype, and other project-related materials for our Final Year Project.

The project focuses on applying **Graph Neural Networks (GNNs)** for detecting anomalous activities in fraud networks by analyzing relationships and patterns within graph-structured data.

## 🔬 Project Scope

The project investigates graph-based approaches for identifying anomalous or potentially fraudulent patterns in network data.

The work includes:

* Graph-based data representation
* Graph Neural Network models
* Community-level analysis
* Anomaly detection
* Machine Learning baseline models
* Model evaluation using standard classification metrics

## 📈 Evaluation Metrics

The project uses commonly used evaluation metrics such as:

* Precision
* Recall
* F1-Score
* ROC-AUC
